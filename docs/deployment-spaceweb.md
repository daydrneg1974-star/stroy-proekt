## Подготовка

`npm run build:spaceweb -- /absolute/path/to/new-empty-directory`

Команда создаёт `public_html` и манифест вне этого каталога. В корне размещается нейтральная страница подготовки; приложение находится в случайном каталоге `review-…` с 144 битами случайности. Точная ссылка доступна в манифесте, её нельзя включать в общедоступную документацию или robots.txt. Доступ по ссылке не является аутентификацией: любой получивший ссылку сможет посмотреть копию. Не размещать там персональные сведения или секреты.

Приложение состоит из прежних 20 публичных файлов. Меняются только домен в метаданных и описание инфраструктуры в двух HTML-страницах. JavaScript и медиа копируются без изменения. В комплект также входят страница подготовки, favicon, robots.txt и два файла Apache `.htaccess` (25 публичных файлов всего). Служебные файлы, манифест, отчёты и тесты в `public_html` не включаются.

HTTPS обязателен: `.htaccess` перенаправляет HTTP на HTTPS с кодом 302, кроме проверки ACME. Листинг каталогов отключён; выдаются `Referrer-Policy: no-referrer`, `X-Content-Type-Options: nosniff` и `X-Robots-Tag: noindex, nofollow, noarchive`. Маршрут `privacy` поддерживается внутри проверочного каталога.

## Размещение и приёмка

1. Сохранить исходное содержимое новой папки перед заменой. Архив загружать в `stroyinzh-dom_ru`, вне публичного каталога.
2. Дождаться корректного делегирования и выпустить бесплатный Let's Encrypt. Не повторять заявку на сертификат без изменения причины отказа.
3. Распаковать только `public_html`. Убедиться, что манифест и архив не доступны по HTTP.
4. Проверить настоящий HTTPS, редирект HTTP, страницу подготовки и отсутствие ссылки на проверочный каталог в её HTML и robots.txt.
5. Проверить копию на телефоне/узком экране, локальные изображения и видео, страницу privacy, ссылки контактов, сохранение ручных пожеланий, копирование и TXT. Отправлять сообщение от имени владельца только по отдельному поручению.

До публичного коммерческого запуска подтвердить исполнителя и оператора, завершить политику и организационные вопросы из `_docs/launch.md`, затем отдельно согласовать публикацию приложения в корне. `noindex` и случайная ссылка не заменяют выполнение применимых требований к обработке данных.
