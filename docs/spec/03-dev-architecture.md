# Архитектура и проверка

Текущая цель — статический сайт на SpaceWeb, https://stroyinzh-dom.ru/. `index.html` содержит оформление и контент, `privacy.html` — доступное без JavaScript описание работы с данными, `project.js` — состав проекта и экспорт текста, `site.js` — обработчики интерфейса. `.htaccess` и `robots.txt` — исходные настройки публикации. Backend, база данных, сторонние runtime-пакеты, аналитика и платные API не используются.

## Обращение

Посетитель видит исполнителя СтройИнжиниринг, телефон +7 (499) 130-66-16 и прямой WhatsApp `https://wa.me/74991306616`. Владелец подтвердил подключение WhatsApp Business к этому городскому номеру. Telegram скрыт: username или мобильный контакт пока не предоставлен. Почты и MAX нет.

`contacts.json` содержит только `whatsapp` и `telegram`, полный URL либо `null`. `scripts/contacts.mjs` проверяет разрешённый домен/формат HTTPS, отсутствие query/hash и отклоняет российский городской номер в Telegram. Конфигурация не создаёт ссылку из телефонного номера. При сборке инструкции, кнопки и ссылки политики формируются только для заданных каналов; `null` не создаёт кнопку или заглушку. Если оба канала отсутствуют, остаются телефон, черновик и его сохранение. HTML в корне содержит маркеры сборки; проверяется готовый `public_html`. В публичном JavaScript нет настройки контактов и изменения ссылок: ввод, добавление состава и восстановление страницы не затрагивают URL.

Посетитель явно копирует полный текст, открывает чат, сам вставляет, проверяет и отправляет сообщение. Сайт не знает результата отправки или доставки. Ссылки открываются с `noopener noreferrer`, обе HTML-страницы задают `referrer=no-referrer`. При недоступном чате предлагается телефон. Служебный статус ожидания контактов хранится в документации, на странице нет пояснений о работе владельца над настройкой.

Форматы сверены с [WhatsApp Click to chat](https://faq.whatsapp.com/5913398998672934) и [Telegram phone number links](https://core.telegram.org/api/links#phone-number-links). [FAQ Telegram](https://telegram.org/faq) допускает аккаунты только на мобильных номерах. Указанный городской номер нельзя превращать в Telegram-ссылку. Синтаксис URL и подтверждение владельца не заменяют проверку реального перехода/доставки: они пока не подтверждены; сообщения не отправлялись.

Ручные заметки сохраняются при добавлении состава/темы; одинаковый блок повторно не добавляется. Копирование и UTF-8 TXT не обрезают текст. Clipboard используется только для записи по кнопке, не для чтения. При отказе API выделяется всё поле для ручного копирования. Черновик находится в памяти вкладки, не записывается в постоянное хранилище и не отправляется сайтом на сервер. У поля `spellcheck=false` и просьба не вводить персональные сведения. Без JS доступны ручная запись/копирование, чаты, телефон и информация о данных; автоматические действия скрыты.

## Данные и внешние ограничения

В коде нет серверного приёма черновика, аналитики и рекламных cookies. При загрузке файлов SpaceWeb получает IP-адрес и технические параметры HTTP-запроса. Историческая проверка 23.11.2026 зафиксировала отключённые в панели журналы посещений, ошибок и AWStats. Это не доказывает отсутствие служебных журналов провайдера; их сроки, география и условия обработки не подтверждены. Наблюдение cookie на прежней площадке Sites не описывает текущее размещение.

`privacy.html` содержит техническое описание и ссылки на правила настроенных мессенджеров (сейчас WhatsApp). Полная политика и реквизиты фактического исполнителя/оператора ещё не оформлены. По сообщению владельца от 22.11.2026 уведомление РКН не подавалось; текущий статус отдельно не проверен. Из технической минимизации нельзя делать вывод о полном юридическом соответствии. Индексация закрыта; noindex не ограничивает доступ к сайту.

## Сборка и обновление

Один источник и одна команда: `npm run build [-- /absolute/new-empty-release]`. Результат — `public_html/` с 26 файлами из `scripts/public-files.mjs` и отдельный `release-manifest.json`. По умолчанию используется `dist/`. Исторические сборщики изъяты из активного дерева и сохранены в Git. Сборка разрешает маркеры контактов по одной конфигурации; других вариантов площадки или отключения обращений нет.

Перед записью читаются все публичные исходники. У HTML, JS, robots.txt и `.htaccess` нормализуются переводы строк и убираются завершающие пробелы/переносы, которые снимает редактор SpaceWeb. Затем рассчитывается SHA-256 готового `project.js`, версия подставляется в импорт `site.js`; после этого SHA-256 готового `site.js` подставляется в HTML. Медиаданные копируются побайтно. Манифест содержит origin, каталог публикации, имена, размеры и SHA-256 всех готовых файлов, без даты и локальных путей. Одинаковые исходники дают одинаковый релиз.

`npm run verify:release [-- /absolute/release]` проверяет состав, размеры, SHA-256 и обе версии модулей. Манифест не размещается в веб-корне. Назначение сборки проверяется до удаления: родительские каталоги и исходники защищены, внешний каталог должен быть пустым, симлинки запрещены. В `.htaccess` сохранены проверенные для прокси SpaceWeb правила HTTPS, абсолютный редирект `/privacy` и `/privacy/`, запрет листинга/служебных файлов и защитные заголовки.

Версия кода, публикация и внешние проверки отражаются в [status.md](../status.md). Порядок резервирования, обновления и отката — [deployment-spaceweb.md](../deployment-spaceweb.md). История Git и сохранённый релиз нужны одновременно: Git описывает исходники, манифест — байты публикации.

## Проверка результата

`npm run check` — синтаксис и Node tests: варианты конфигуратора, сохранение заметок, полный Clipboard/TXT, ошибки платформенных API, неизменные URL, отсутствие автопереходов/отправки, контакты без JS, локальные ссылки, дословные отзывы, безопасность и воспроизводимость сборки. Проверяются основной CLI, точный allowlist, нормализация до хеширования и обнаружение изменения релиза. DOM fixture не заменяет браузер.

Локальная браузерная проверка готового `public_html`: 320/360/768/1024/1440 px, светлая/тёмная темы, отсутствие горизонтального скролла, меню, клавиатура, конфигуратор, ручные заметки, реальный Clipboard, скачанный TXT и режим без JavaScript. При открытии чата можно проверить адрес перехода без отправки сообщения; наличие аккаунта при этом не предполагается. После публикации отдельно проверяются HTTPS, редиректы, заголовки, все файлы по манифесту и недоступность служебных данных. Локальная проверка не подтверждает серверные настройки.

История: T05 заменила перенос текста через URL на ручное копирование; T06 возвращает явные контакты в единую сборку SpaceWeb. Прежние задачи и отчёты сохраняют свой исторический смысл.
