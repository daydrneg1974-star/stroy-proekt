## Описание

После публикации v3 (исходники 3ab23585) новый адрес daydrneg1974 запускает контроллер, перенос, копирование и TXT. На ранее посещённом keenpanda11 наблюдаются новое HTML/название/демостатус, но нет класса js-enabled и остаются скрытыми data-js-only; повторная загрузка не помогает. Вероятная причина — старая копия неизменившегося URL site.js в кеше; HTTP-механизм здесь ещё не доказан.

Уточнение основного агента: в свежем Cloud Browser прежний адрес автоматически перенаправляет на https://stroyengineering-demo-rifkat.daydrneg1974.chatgpt.site/ и контроллер запускается. В прежнем Chrome-профиле адрес остался старым; отдельное открытие script URL дало ERR_BLOCKED_BY_CLIENT. Эти наблюдения не устанавливают причину: версии ресурсов добавляются как защита от смешивания выпусков. canonical и og:url должны использовать подтверждённый действующий адрес.

Добавить версии по содержимому к URL entrypoint и его зависимого модуля. Использовать SHA-256 и встроенный Node, сохранить исходники единственным источником публикации, без дополнительных публичных файлов. Автотест должен отклонять рассогласованные ссылки при следующем изменении JS. Не требовать от пользователя hard reload. Браузер, commit/push/deploy выполняет основной агент после независимой проверки.
