## Описание

Пользователь прямо поручил автономно внести необходимые исправления по скиллам курса и проверить результат. Дополнительные согласования обычных исправлений и публикации существующей демоверсии не нужны. Реальная ручная приёмка владельцем не заявляется. Не подключать сервисы, платные тарифы, приём заявок, аналитику, домен; не добавлять реквизиты, цены или факты о компании.

Сохранить существующую светлую/тёмную тему, структуру и целиком показанное фото в hero. Исправить отсутствующую мобильную навигацию, семантику групп полей, видимый focus, контраст, отступы якорей, reduced motion. Убрать противоречия «Рассчитать смету»/«Калькулятор» при отсутствии цен: использовать «Собрать проект»/«Состав проекта». Вместо мёртвой формы с личными данными дать локальный редактируемый черновик состава с копированием и скачиванием TXT, честным статусом ошибки копирования и без скрытого хранения. При изменении выбора показывать актуальный состав рядом; перенос/карточки не должны молча уничтожать пользовательский текст. Контакты показать как «Будут добавлены перед запуском», демостатус — коротко и ясно. Существующую политику-заглушку заменить фактическим описанием поведения демоверсии без юридических обещаний. Удалить выдуманные отзывы. Никаких новых фактов о компании.

Устранить старые неиспользуемые app.js/style.css и PHP из выкладываемого dist. Документацию об историческом PHP сохранить в истории Git, файл не должен создавать ложную готовность бэкенда. Сделать один источник исходников и минимальную сборку в dist с явным разрешённым списком; тесты встроенным Node без новых зависимостей на полезное поведение конфигуратора и безопасность экспорта. Локальные картинки оптимизировать без смены содержания и композиции, задать размеры и responsive srcset; видео не загружать заранее. Сторонние запросы для шрифтов убрать, если возможно сохранить типографику без нового сервиса. robots noindex оставить, favicon и social metadata согласовать с демостатусом.

Результат и измерения записать в журнал. Не делать commit/push/deploy: это делает основной агент через Sites после независимой проверки.
