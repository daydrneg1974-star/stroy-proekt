# T05 — браузерная проверка

22 ноября 2026 года, root. Управляемый preview `http://127.0.0.1:4173/`, Chromium через CUA. Использованы только синтетические тексты, сообщений не отправляли.

- В поле введены Unicode и символы URL; после добавления состава исходные пожелания сохранены. Реальный буфер обмена совпал с полным текстом, в том числе с черновиком длиной 7200 символов. Telegram и WhatsApp остались `https://t.me/+74991306616` и `https://wa.me/74991306616`, без query/hash.
- Страница `privacy.html` открылась из контактов в отдельной вкладке; исходный черновик сохранился. Открытие с клавиатуры проверено. Первый pointer-click попал между строками переносимой inline-ссылки: root добавил `#draft-privacy a{display:inline-block}`. Повторная проверка pointer-click открыла страницу. Из подвала переход в той же вкладке также подтверждён.
- Главная проверена в iframe с ширинами 320/360/768/1024/1440 CSS px. Из-за полосы прокрутки ширина содержимого 305/345/753/1009/1425; `scrollWidth` равен `clientWidth` в каждом случае. На 320 px видны три шага, затем копирование/TXT и ссылки чатов. Кнопки имеют высоту 48 px, ссылки мессенджеров 56 px; перекрытий в проверенном положении нет.
- `privacy.html` проверена на 320/360/1440 в светлой и тёмной теме, горизонтального переполнения нет. Визуально найден некрасивый перенос последней части длинного заголовка; root уменьшил мобильный размер до `clamp(24px,7.5vw,34px)`. Повторно проверены 320/360 px: заголовок занимает две строки, слово целиком помещается; скриншот 320 px подтверждает результат.
- В отдельном iframe без `allow-scripts` инструкция по ручному копированию, телефон, обе базовые ссылки и информация о данных доступны. Кнопки JS-действий отключены. Ручное выделение и Ctrl+C дали в реальном Clipboard точный текст `Без JavaScript: баня и терраса.`. Переход из подвала открыл страницу данных без JS. Её текст, телефон и обратная ссылка доступны.
- Проверка URL не является подтверждением регистрации номера в мессенджерах или доставки сообщения. Новых сообщений, входа в аккаунты и реальных заявок не было. Синтетические черновики очищены.

QA-обёртка `__qa.html` временная и не входит в allowlist. Финальная сборка перед публикацией должна оставить только 20 публичных файлов.
