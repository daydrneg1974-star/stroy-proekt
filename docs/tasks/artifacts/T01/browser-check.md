# Браузерная проверка T01

Дата: 2026-11-21. Выполнил основной агент через управляемый браузер, отдельно от Node-проверки verifier. Это не ручная приёмка владельцем и не тест на физическом телефоне.

## Локальная опубликованию готовящаяся сборка

Адрес preview: http://127.0.0.1:4173/. Временный `__qa.html` задавал viewport iframe, тему и sandbox без JavaScript. Он не входит в разрешённый список и удаляется финальной сборкой.

| Проверка | Результат |
|---|---|
| Ширины 320/360/768/1024/1440, light и dark | Во всех 10 сочетаниях scrollWidth=clientWidth: 305/345/753/1009/1425 (15 px scrollbar). Горизонтального переполнения нет |
| Мобильное меню | Открытие, Escape и выбор раздела закрывают меню; aria-expanded меняется |
| Якорь «Состав проекта», 360 px | Верх цели 93,23 px при нижнем крае шапки 77 px: заголовок не перекрыт |
| Клавиатура и конфигуратор | End даёт 400 м², Home — 60 м². Материал и пруд отражаются в составе |
| Инженерия | В «Под чистовую» checkbox checked+disabled, дополнительная инженерия отсутствует в тексте |
| Перенос и повтор | Ручной текст «Сохранить яблоню и оставить место для мастерской.» сохранился; двойное добавление не дублирует блок |
| FAQ | Enter открывает details «Как вызвать инженера на участок?» |
| Без JavaScript | Навигация и textarea доступны, slider скрыт; ссылка «Контакты» работает. Шапка не закреплена, якорь не перекрывается |
| Clipboard, отдельная страница | Реальный буфер содержит точно «Проверка экспорта: сохранить яблоню.», интерфейс показывает успех |
| TXT, отдельная страница | Получено событие download и существующий файл; прочитанные байты: UTF-8 BOM + точно «Проверка экспорта: сохранить яблоню.» |
| Console | В доступной выборке нет ошибок страницы/загрузки ресурсов. Сообщения chrome-extension о передаче browser metadata относятся к инструменту автоматизации |
| Визуальная проверка | Просмотрены первый экран desktop light, 320 px dark и блок черновика. Оформление и полное фото сохранены |

В iframe ожидание скачивания истекло, а Clipboard после переключения sandbox не завершился. Поэтому успех экспорта не выводился из статуса кнопки: оба сценария повторены на отдельной странице без iframe и подтверждены буфером/байтами файла. Исходный таймаут не объявлен ошибкой сайта.

## Границы доказательств

Нет испытаний физических устройств, Safari/iOS, скринридера со звуком, производственного потока лидов и полной сертификации WCAG. Пять ширин не означают проверку каждой возможной ширины. Этот протокол относится к локальной сборке; после развёртывания выполняется отдельная проверка live URL.
