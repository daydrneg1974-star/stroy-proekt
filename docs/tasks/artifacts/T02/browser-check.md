## Отдельная проверка Cloud Browser

Обычная перезагрузка v4 показывает тот же SHA-256 URL контроллера. Реальное содержимое Clipboard совпадает с составом проекта; скачивание TXT завершено. В доступной выборке ошибок сайта нет.

После проверки viewport восстановлен, тестовый текст очищен. Это браузерная проверка основного агента, не ручная приёмка владельцем и не испытание физического телефона.

## Причина первоначального симптома

Исходное сочетание нового HTML с неинициализированным контроллером было наблюдаемым симптомом. В прежнем профиле также наблюдался `ERR_BLOCKED_BY_CLIENT`, а свежий браузер перенаправлялся на новый адрес. Конкретная причина не установлена; кеш остаётся одной из гипотез. Версии по содержимому проверены как защита от смешивания выпусков. Успешный запуск v4 сам по себе не доказывает единственную причину прежнего сбоя.
