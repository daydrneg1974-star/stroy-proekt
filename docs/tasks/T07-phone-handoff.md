# СтройИнжиниринг — приёмка T07 на подключённом телефоне

Работай автономно в локальном Codex на Windows. Цель — проверить текущую неопубликованную T07 на действительно подключённом Android, устранить только подтверждённые дефекты и сохранить доказательства. Пользователь сообщил, что телефон подключён. Не проси переподключать его без фактической ошибки ADB. Не выдавай эмулятор или настольный responsive viewport за телефон.

Исходники находятся в приложенном Git bundle `stroy_t07.bundle`, ветка `codex/t07-reliability-local`. GitHub `daydrneg1974-star/stroy-proekt` main пока содержит T06; одного клонирования GitHub недостаточно. Проверь bundle и создай отдельную папку проекта на компьютере владельца, например `C:\Users\admin\Documents\Codex\stroy-proekt`, если она свободна. Если проект уже есть, сначала проверь локальные изменения и историю; ничего не затирай и не делай reset. Получи ветку из bundle, не применяй старый патч T07 второй раз.

Прочитай AGENTS.md, README.md, docs/status.md, T07-e2e-acceptance-20261126.md, T07-local-followup-20261126.md и T07-php-browser-20261126.md. Уже подтверждены desktop e2e 4/4, Node 45/45, реальные 200%, сохранённые TXT и нативный запрет Clipboard. Дополнительно PHP browser 8/8 и PHP 69/69 PASS; исправлена видимость ошибок в закрытом блоке серверной формы. Не повторяй эти проверки без новых изменений или диагностической необходимости. Если уже работаешь с прежним пакетом HEAD f58a7a4, сохрани свои изменения и доказательства: новая версия меняет только отдельную серверную форму, результаты главной страницы не аннулируются. Новые исходники получай из обновлённого bundle без reset и перезаписи локальной работы.

Серверную отправку оставить выключенной. Не выполнять push, merge, публикацию, изменение DNS/почты, реальные звонки и сообщения. Не менять остальные проекты. Отзывы, Dzit, дизайн и контакты сохранить. Не запрашивать снова уже отложенные SMTP/реквизиты/Telegram/MAX. Подтверждённый владельцем WhatsApp Business не нужно перепроверять отправкой сообщения.

Используй установленный ADB и локальный браузер телефона. Зафиксируй модель/версию Android/браузера и состояние подключения, не раскрывая серийный номер в итоговом публичном отчёте. Если устройств несколько, не выбирай случайное. Тестируй собранную T07 через локальный сервер и адрес, доступный по ADB reverse, например 127.0.0.1:4173. Не выставляй сервер в Интернет. Для PHP используй настоящий PHP 8.2+; не раздавай PHP-файлы как текст статическим сервером. Не меняй настройки сети/безопасности телефона шире необходимого локального теста. Не удаляй данные браузера или пользовательские загрузки.

Критерии приёмки:

- Меню, якоря и кнопки доступны касанием, шапка/нижняя панель не перекрывают целевые действия; нет горизонтального переполнения в портретном и альбомном режиме.
- Конструктор → состав → ручные заметки → сброс: заметки сохранены, состав соответствует выбору; повторное добавление не создаёт дубль.
- Копирование соответствует полному синтетическому черновику. При реальном отказе разрешения, если браузер позволяет его задать, сохранён ручной путь. Если такой режим недоступен, честно NOT RUN, не подмена navigator.clipboard.
- TXT действительно сохранён телефоном. Проверить размер/UTF-8/BOM/содержимое длинного текста, повтор после редактирования и сброса; одного сообщения кнопки недостаточно. Использовать только синтетические данные, без ФИО/телефонов/адресов.
- Проверить доступность нужных элементов при увеличенном масштабе/шрифте телефона и работу экранного диктора в доступном объёме. Временные настройки вернуть; не требовать сброса устройства.
- Телефон и WhatsApp доступны как правильные ссылки; отправку и звонок не выполнять. Отключённая форма сообщает о недоступности. Сайт на SpaceWeb этим тестом не заменять.

Сохранить новый отчёт и доказательства отдельно от старых. Если найдены дефекты — минимальное исправление и адресная повторная проверка плюс необходимые проверки проекта. Если дефектов нет — не менять продуктовый код. Итог: что прошло, что осталось, реальное устройство, проверяемая версия, локальный коммит и папка проекта. Push и публикацию не выполнять.
