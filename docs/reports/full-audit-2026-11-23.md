# Полная техническая проверка СтройИнжиниринг — 23 ноября 2026

Проверен сайт https://stroyinzh-dom.ru/ и конкретная сборка для SpaceWeb. Режим: публичная демонстрация без приёма заявок, контактов подрядчика, платежей и расчёта стоимости. Индексация отключена. Это техническая приёмка, а не заключение о полном соответствии законодательству.

## Объём

Прочитаны обе HTML-страницы, оба JavaScript-модуля, все четыре сборочных скрипта, список публичных файлов и тесты. Проверены 13 секций главной страницы, отдельная страница «Данные и конфиденциальность», изображения, SVG и видео. Исторические документы не являются кодом действующего сайта.

## Найдено и исправлено

1. Редактор SpaceWeb убирает завершающий перенос строки. Публичная сборка нормализует редактируемые файлы до расчёта SHA-256; версия site.js в HTML соответствует реальным байтам сервера.
2. Из description страницы о данных убрано оставшееся упоминание мессенджеров.
3. Адрес og:image заменён на полный HTTPS-адрес домена.
4. Варианты /privacy и /privacy/ перенаправляются на https://stroyinzh-dom.ru/privacy.html. Прежняя внутренняя подстановка ломала относительные ссылки при завершающем слеше. Относительное перенаправление на этом хостинге также давало серверный путь; окончательное абсолютное правило проверено: 302 → 200.

Ранее при подготовке публикации были исправлены цикл перенаправления за прокси SpaceWeb и обращение JS к отсутствующим кнопкам мессенджеров. Удалены из публичного HTML контакты и инструкции отправки заявки. Исходная копия Sites сохранена отдельно и не обновлялась этой публикацией.
