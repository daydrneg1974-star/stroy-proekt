# Локальная проверка интерфейса

Из корня проекта:

```sh
npm run check
npm run e2e
npm run build
npm run verify:release
```

`npm run e2e` запускает `contact-release.browser.mjs` инструментом `node:test`. Тест сам собирает готовый сайт во временную пустую папку, поднимает HTTP-сервер на `127.0.0.1` и случайном порту, запускает отдельный headless Chromium, затем закрывает браузер/сервер и удаляет временный релиз. Подключённый браузер владельца не используется.

Нужны доступные Playwright и Chromium. В подготовленном runtime Playwright загружается из `CODEX_PRIMARY_RUNTIME_NODE_MODULES/playwright/index.js`. Другой существующий модуль можно указать через `STROY_PLAYWRIGHT_MODULE` (абсолютный путь к index.js). В обычном окружении без этих переменных используется установленный пакет `playwright`. Тест ничего не устанавливает автоматически.

`STROY_CHROMIUM_PATH` может указывать на уже установленный браузер. Без переменной используется существующий бинарник `/usr/lib/chromium/chromium`, иначе браузер, установленный для Playwright. Одного launcher `/usr/bin/chromium` недостаточно. Отсутствующая зависимость или браузер — ошибка проверки, а не пропуск/PASS.

Покрытие тремя независимыми сквозными сценариями:

- Контакты, отсутствие Telegram/MAX/email, политика и отсутствие горизонтального скролла: 320/360/768/1024/1440 px, JavaScript включён/выключен, светлая/тёмная темы, мобильное меню с Escape.
- Длинные ручные заметки, крайняя площадь 400 м², материал/допработы, повторное добавление состава, настоящий Clipboard, фактически скачанный UTF-8 TXT, переход на прямой адрес чата, отсутствие хранения/отправки и потеря локального черновика после подтверждённой перезагрузки.
- Пустой ввод, принудительный `NotAllowedError` Clipboard с проверкой полного выделения, TXT после отказа буфера и ошибка подготовки TXT без потери текста.

Все внешние запросы блокируются. В сценарии перехода точный `https://wa.me/74991306616` получает локальный тестовый HTML через `route.fulfill`; наблюдается запрос навигации и его отсутствие текста/referrer, но реальный WhatsApp не вызывается. Проверка не подтверждает аккаунт, доступность сервиса или доставку сообщения.

Текстовые наблюдения — `docs/tasks/artifacts/T06/browser-observations.json`; скриншоты — в соседней `screenshots/` (не входят в Git). `STROY_E2E_ARTIFACTS` меняет папку результатов. Для сохранения вывода:

```sh
npm run e2e > docs/tasks/artifacts/T06/browser-test.log 2>&1
```

Код выхода команды обязателен к проверке: наличие файла наблюдений само по себе не доказывает успешный запуск браузера.
