Сайт: https://stroyinzh-dom.ru/ · размещение на SpaceWeb. Репозиторий: https://github.com/daydrneg1974-star/stroy-proekt.

Статический сайт HTML/CSS/JavaScript: посетитель собирает состав работ, добавляет свои заметки, копирует полный текст, открывает WhatsApp, сам вставляет и отправляет сообщение. Исполнитель, указанный владельцем, — СтройИнжиниринг; телефон — +7 (499) 130-66-16. Цена не рассчитывается. Почты, MAX, backend, базы данных, аналитики и сторонних виджетов нет.

**Телефон и WhatsApp опубликованы на SpaceWeb 26.11.2026.** Telegram скрыт до получения контакта; MAX отложен. Точный статус проверок и внешних ограничений — [docs/status.md](docs/status.md). Предыдущий опубликованный вариант без контактов сохранён в архивной ветке GitHub и на хостинге.

## Работа с проектом

Нужны Node.js 22+ и npm. Сайт, unit-проверки и сборка не требуют внешних зависимостей. Для отдельной обязательной проверки интерфейса нужны доступные Playwright и Chromium.

```sh
npm run check
npm run build
npm run verify:release
npm run e2e
```

`npm run check` проверяет синтаксис и запускает Node tests. Основная и единственная сборка — `npm run build`: она создаёт `dist/public_html/` и `dist/release-manifest.json`. На сервер загружается **только содержимое `public_html`**. Манифест, исходники, документация и архивы остаются вне веб-корня.

`npm run e2e` отдельно запускает `e2e/contact-release.browser.mjs` в локальном Chromium и обязателен перед выпуском. Путь к установленному модулю Playwright задаётся через `STROY_PLAYWRIGHT_MODULE`; альтернативно используется каталог `CODEX_PRIMARY_RUNTIME_NODE_MODULES`. Исполняемый файл Chromium задаётся через `STROY_CHROMIUM_PATH`, по умолчанию — `/usr/bin/chromium`. На другой машине, включая Windows, нужно указать реальные пути её установленных инструментов. При недоступных Playwright/Chromium проверка завершается ошибкой: отсутствие зависимостей не считается успешным тестом и не должно скрываться пропуском. Unit-проверки и сборка от этих инструментов не зависят.

Для отдельного сохраняемого релиза:

```sh
npm run build -- /absolute/path/to/new-empty-release
npm run verify:release -- /absolute/path/to/new-empty-release
```

На Windows вместо этого пути укажите новый каталог, например `C:\Projects\stroyinzh-releases\release-001`. `dist/` можно пересобирать; другой каталог должен быть новым или пустым. Сборка отказывается перезаписывать исходники, родительский каталог, непустую внешнюю папку или путь через символическую ссылку.

Редактируются корневые `index.html`, `privacy.html`, `site.js`, `project.js`, `contacts.json`, `.htaccess`, `robots.txt` и `assets/`. `scripts/public-files.mjs` задаёт единственный allowlist публикации — 26 файлов. Сборка нормализует редактируемые текстовые файлы для редактора SpaceWeb, затем рассчитывает версии `project.js` и `site.js` по SHA-256 готовых байтов. Манифест не содержит времени и локальных путей: из одинаковых исходников получаются одинаковые файлы и манифест. Хеши вручную не обновляются. `dist/` не редактировать и не коммитить.

Ссылки задаются только в `contacts.json`: `whatsapp` и `telegram`, URL либо `null`. `null` убирает кнопку и относящиеся к каналу инструкции/ссылку политики из готовых HTML. Добавлять только предоставленные владельцем контакты; не выводить их из телефона. Сборка проверяет формат HTTPS, адрес сервиса, отсутствие query/hash и отклоняет российский городской номер Telegram. Это проверка синтаксиса, а не аккаунта. `scripts/contacts.mjs` подставляет инструкции в HTML при сборке, поэтому локально проверять нужно `dist/public_html`, а не открывать HTML-шаблон в корне. Конфигурация не публикуется.

## Обращение и ограничения

- WhatsApp: `https://wa.me/74991306616`. Владелец подтвердил подключение WhatsApp Business к этому городскому номеру. Ссылка не содержит текста, query или hash; переход не копирует и не отправляет сообщение автоматически.
- Подтверждение владельца о WhatsApp и независимая проверка доставки — разные факты: сообщение не отправлялось, реальное открытие чата в браузере не подтверждено. При недоступном чате остаётся телефон. Telegram скрыт до получения username или мобильного контакта; городской номер для него не подходит.
- Черновик существует в памяти вкладки. Копирование и UTF-8 TXT сохраняют весь текст, включая ручные заметки. При отказе Clipboard поле выделяется для ручного копирования. Код не читает буфер, не отправляет черновик на сервер и не сохраняет его в постоянное браузерное хранилище.
- Без JavaScript доступны телефон, прямые ссылки, поле и инструкция ручного копирования. Интерактивный выбор состава, автоматическое копирование и TXT требуют JavaScript.
- [Данные и конфиденциальность](privacy.html) — техническое описание, доступное без JavaScript. Реквизиты фактического исполнителя/оператора и полная политика ещё не оформлены. Технические данные обрабатываются инфраструктурой хостинга; отсутствие аналитики в коде не означает отсутствие такой обработки.
- `noindex` сохранён в HTML, robots.txt и заголовке Apache. Это не ограничение доступа к публичному сайту.
- Три исходных отзыва сохранены дословно. Галерея Dzit и её подпись сохранены; сведения о происхождении медиа — [_docs/images.md](_docs/images.md).

Проверка интерфейса: узкие и широкие экраны, обе темы, меню и клавиатура, конфигуратор, сохранение заметок, полный Clipboard/TXT, отказ Clipboard, неизменность ссылок и режим без JS. Сообщения для проверки без отдельного поручения не отправлять. Выполненные проверки находятся в `docs/tasks/artifacts/`; исторические отчёты описывают только указанные в них версии и даты.
