# СТРОЙИНЖИНИРИНГ — демоверсия

Публичный сайт: https://stroyengineering-demo-rifkat.daydrneg1974.chatgpt.site/

Статический HTML/CSS/JavaScript. Клиент готовит заявку на сайте, копирует текст, открывает Telegram или WhatsApp, сам вставляет и отправляет сообщение в мессенджере. В коде сайта нет базы данных, серверного приёма заявок, платных API и PHP. Получатель обоих чатов и телефон подрядчика — +7 (499) 130-66-16, предоставленный владельцем. Три исходных отзыва восстановлены по его прямому подтверждению подлинности; цитаты сохранены без изменений и выдуманных имён. Цены не рассчитываются. Коммерческий запуск требует материалов из [_docs/launch.md](_docs/launch.md).

## Исходники и проверка

Исходники — в корне и `assets/`. `dist/` — результат сборки, вручную его не редактировать. Сборка копирует только разрешённые публичные файлы, исключая документы, тесты и старый обработчик.

Команды определены в `package.json`; нужны Node.js 22+ и npm. Сторонних runtime-зависимостей нет.

```sh
npm test
npm run build
npm run check
```

В браузере проверить меню, переходы, выбор площади и комплектации, перенос состава и сохранение ручного текста, неизменность обеих ссылок чатов при любом черновике, копирование/скачивание полного длинного текста, FAQ, страницу данных без JS, светлую/тёмную тему, клавиатуру и увеличенный масштаб. Открытие чата не подтверждает отправку; тестовые сообщения без отдельного поручения не отправлять. Протокол выполненных проверок — `docs/reports/` и `docs/tasks/artifacts/`.

## Поведение демоверсии

- Конфигуратор собирает состав работ, не рассчитывает цену.
- Черновик существует в памяти вкладки. Копирование/скачивание сохраняет его у посетителя, не отправляет подрядчику.
- Ссылки `https://t.me/+74991306616` и `https://wa.me/74991306616` всегда содержат только адресата, без query, hash и текста черновика. Текст не передаётся через URL независимо от длины и символов. Клиент сам копирует полный черновик, открывает чат, вставляет, проверяет и отправляет сообщение. Сайт не знает результата отправки или доставки.
- Прежние лимиты переноса удалены: копирование и UTF-8 TXT сохраняют полный текст. Отказ Clipboard не скрывается: поле выделяется для ручного копирования. Clipboard используется только для записи по явной кнопке; сайт не читает буфер и не открывает чат автоматически.
- Поле предназначено для состава работ и общих пожеланий; рядом просьба не вводить персональные сведения. Проверка правописания отключена. В коде нет аналитики и рекламных cookies; это не исключает обработку IP-адреса, параметров запроса и cookies инфраструктурой.
- Доступная без JS страница [«Данные и конфиденциальность»](privacy.html) связана с контактами, подвалом и прежним якорем `#privacy`. На обеих страницах установлен `referrer=no-referrer`. В публичном ответе 22.11.2026 наблюдался защитный cookie `__cf_bm`; его значение не сохраняется. Настройки инфраструктуры, сроки хранения технических данных и география баз/журналов не подтверждены.
- В контактах, FAQ, подвале и мобильной панели есть обычные ссылки `tel:+74991306616`, работающие без JavaScript. Без скриптов доступны прямые чаты Telegram/WhatsApp и инструкция ручного копирования. MAX отложен владельцем до предоставления ссылки.
- Доступность чата зависит от аккаунта и клиента мессенджера: Telegram разрешает номер с учётом настроек приватности, WhatsApp требует активного аккаунта. Если чат недоступен, остаётся второй мессенджер или телефон. Подтверждение доставки в объём проверки ссылок не входит.
- `noindex` оставлен до готовности рабочего сайта.
- Иллюстрации не являются подтверждённым портфолио. Ограничения: [_docs/images.md](_docs/images.md).

Техническая минимизация T05 заменила требование T04 о передаче черновика через URL по результату проверки приватности; история T04 сохранена. Это не подтверждение полного юридического соответствия. Реквизиты оператора ещё не получены, по сообщению владельца уведомление РКН не подавалось; полная политика и условия обработки/хостинга требуют отдельного подтверждения.
