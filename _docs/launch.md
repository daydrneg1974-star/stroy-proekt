## Обращения и данные

Посетитель сам копирует текст, открывает утверждённый контакт, вставляет и отправляет сообщение. В URL не включается черновик. Clipboard/TXT сохраняют полный текст у посетителя; отказ буфера должен оставлять ручной способ. Сайт не показывает доставку и не отправляет сообщения автоматически. Наличие прямой ссылки не доказывает, что соответствующий аккаунт существует и принадлежит исполнителю. Проверить контакты на реальном устройстве; контрольное сообщение отправлять только по прямому поручению.

`privacy.html` — доступное без JavaScript техническое описание. Черновик не поступает на сервер сайта, постоянного хранилища и аналитики в коде нет. Хостинг при этом получает IP-адрес и технические HTTP-параметры. В панели при проверке 23.11.2026 были отключены журналы посещений, ошибок и AWStats; служебные журналы провайдера этим не исключаются. Наблюдения cookie прежней площадки Sites не переносятся на SpaceWeb.

Реквизиты оператора ещё не получены. По сообщению владельца от 22.11.2026 уведомление РКН не подавалось; последующие действия не подтверждены. После получения фактических сведений определить цели и основания обработки, получателей, условия поручения хостингу, географию и сроки хранения/удаления, применимые уведомления; подготовить полную политику под реальные процессы. Не объявлять юридическое соответствие по одному техническому аудиту.

Backend, email, платежи, аналитика и сторонние виджеты в текущую задачу не входят. Если они потребуются, оформлять отдельную задачу с полями, получателями, хранением, защитой от спама и серверной валидацией. Секреты не помещать в публичную сборку.

## Проверка перед трафиком

- Пройти путь «услуга → состав → заметки → копирование/TXT → контакт» на реальном телефоне, с клавиатуры и при увеличенном тексте; проверить режим без JavaScript.
- Проверить полный длинный текст и неизменность ссылок независимо от содержимого черновика, ручную вставку и доступность страницы данных.
- Выполнить `npm run check`, `npm run build`, `npm run verify:release`; сохранить релиз, исходный commit и рабочую точку отката. Порядок — [deployment-spaceweb.md](../docs/deployment-spaceweb.md).
- Подтвердить настоящую папку проекта на Windows владельца и возможность восстановить проект из GitHub/релиза.
- Проверить срок домена, тариф, лимиты, сертификат и восстановление по фактической панели. Исторический аудит не заменяет текущую проверку.
- Noindex оставлять до отдельного решения владельца и готовности содержания. Его снятие и подключение аналитики не входят в T06.

Исходные отзывы сохраняются дословно по подтверждению владельца; для новых отзывов получать исходный текст и разрешение. Не добавлять имена, оценки, числовые гарантии и штрафы без подтверждённого основания.
